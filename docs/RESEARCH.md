# Research notes: annotated bibliography

Status: this library does not exist yet. This file records what the design was checked against. Every "decision informed" entry is a design inference, not an empirical result of the cited work. Nothing here has been implemented or run.

## How to read the evidence tags

| Tag | Meaning |
|---|---|
| `[read full text]` | The body text was opened. Where the survey recorded which sections were read, they are named. It does not mean the whole paper or appendices were read. |
| `[read abstract]` | Only the full abstract and metadata were read. |
| `[summary only]` | Only a search snippet or a second-hand description was seen. No claim rests on it alone. |
| `[read source]` | (Projects) Source code, issues and pull requests were read in a shallow clone at a pinned commit. Nothing was built or executed, and live behaviour was not observed. |
| `[read docs]` | Official documentation or a specification page was read. The implementation was not. |

Notes on the tags:

- Levels are copied from the literature and survey reports. None was upgraded.
- Where two reports read the same item at different depths, the deeper reading is shown with a note.
- Issue and pull-request numbers belong to the named upstream project.
- Issue counts in the surveys are keyword hits, not defect counts. They are not used as defect rates anywhere.
- The NeoGraph audit is one self-reported audit, so the defect classes it yields are observations and not incidence rates.

Citations carry no URLs. Each has title, year, and the arXiv id or DOI where the source reports gave one.

## 1. Reasoning state and security

| Citation | Level | What it shows | Decision informed |
|---|---|---|---|
| *Stealing Reasoning Traces from Proprietary LLM APIs*, 2026, arXiv:2608.09867 | `[read full text]` §2.1–2.5, §5.1–5.5, reproducibility statement | Opaque reasoning traces can carry sensitive content or hidden injected instructions. The authors state the demonstrated attack no longer reproduced after a vendor mitigation in August 2026. | Reasoning bytes are secret-bearing opaque state. They are kept out of logs, exceptions and public fixtures. The origin tag is client-side defence in depth and is never described as cryptographic. No claim that providers are currently exploitable. |
| *Not what you've signed up for: Compromising Real-World LLM-Integrated Applications with Indirect Prompt Injection*, 2023, arXiv:2302.12173 | `[read full text]` v2, §1–3.1, part of §3.2 | Retrieved data can be interpreted as instructions, which steers API use and information flow. | Stored outputs, replayed transcripts and foreign reasoning are never promoted to trusted instructions. | *LLM-Rosetta: A Hub-and-Spoke Intermediate Representation for Cross-Provider LLM API Translation*, 2026, arXiv:2604.09360 | `[read full text]` §3–5.6, §6.1–6.2 | Typed IR, per-family converters and stateful stream events. Cross-provider evaluation is 10 tests and the authors acknowledge a circular-validation risk. "Lossless" means same-format structural round trip. | Per-family typed codecs feeding one semantic vocabulary. "Lossless" is never read as cross-vendor reasoning portability. The Open Responses attribution to a specific company in the paper is not repeated because the survey could not confirm it. |
| *Considered, rejected*: multi-vendor reasoning continuation as a capability negotiation | n/a | No reviewed work demonstrates native reasoning continuation across vendors. | Foreign native replay is refused by default, with explicit opt-in Drop or Demote only. ### 2.2 Surveyed projects (source read, not executed)

| Project | Level | What it shows | Decision informed |
|---|---|---|---|
| LiteLLM | `[read source]` | OpenAI-shaped lingua franca, code-heavy per-provider classes, a thin JSON layer only for about 30 OpenAI-compatible providers and model capability flags. EOF and unknown finish reasons are synthesized as "stop". Quota-exhausted 429 is not distinguished from rate limiting (open issue). Retry is layered across SDK, router and tenacity. Foreign `thinking_blocks` leak to OpenAI-compatible backends (open issues). | Truncated stream is a failure, never "stop". Quota 429 is never retried. Exactly one retry layer. Origin-aware conversion from the start. Gemini token-sum check reused as a usage invariant. |
| rig (Rust) | `[read source]` | Closest structural relative: per-vendor data as Rust constants plus a closed rewrite enum. Single decoder shared by buffered and streamed responses. Frames classified Known, Unknown or Corrupt. Reasoning stored as a sealed value tagged with its issuer, and foreign issuers are dropped at encode time. Buffered-versus-stream parity test over about 3,000 recorded replies. No retry executor, no jitter, no quota distinction. Closed enums fail whole responses on new vendor values. | One decoder and one fold for all transports. Known/Unknown/Corrupt frames. Origin-sealed reasoning. The parity test idea is generalized to `TransportProjectionParity`. The rewrite-enum growth is the cautionary case for bounding descriptor rules. |
| genai (Rust) | `[read source]` | Hand-written adapters over JSON values. No origin tag on thought signatures. Unknown content blocks are preserved with the model identity. EOF without a terminal event is reported as normal end. Library exposes status and headers and leaves retry to the caller. | Capture reasoning and signatures by default, not opt-in. Preserve unknown payloads verbatim. Terminal evidence is required. |
| async-openai (Rust) | `[read source]` | Typed structs aligned to one vendor's OpenAPI. Closed enums and required fields break on compatible providers. The only surveyed library that reads a 429 body and treats `insufficient_quota` as permanent. A reader task leaked when the consumer dropped the stream (fixed). | Tolerate harmless unknown fields but fail known-malformed ones. Quota-exhausted 429 classified by machine-readable body, not status. Consumer-drop and cancel are tested. |
| graniet/llm (Rust) | `[read source]` (shallow) | Signatures not preserved, so tool-loop replay cannot work. A "jitter" value derived deterministically from the attempt index. Every error class is retryable. | Negative examples only. Jitter must be random with an injectable RNG and clock. |
| Vercel AI SDK | `[read source]` | Typed codecs per vendor plus shared spec types. Origin is a provider-name key namespace. Usage normalized to an explicit total/noCache/cacheRead/cacheWrite/reasoning/raw shape. Spec versions are duplicated directories with a lossy proxy adapter and a source note that it may break. Five vendor packages each copied one parser and fixed the same reasoning bug five times. Retry has no jitter. | Explicit usage shape with raw values kept. Versioned grammar with explicit migration rather than a proxy adapter. One shared decoder per family, not copies per vendor. |
| genai-prices (used by Pydantic AI) | `[read source]` | Usage mapping declared as data: several source paths summed into one destination, with a unit registry that rejects unknown destinations. The path language is not allowed to grow. |
| Pydantic AI | `[read source]` | Explicit provider name on thinking parts. Same provider replays verbatim, other providers get text demotion. Demoting an unsigned last thinking block on the same provider caused a 400 (open issue). Cassettes are body-insensitive by default and the project says so. A wire-probe test checks that each declared setting reaches the request. Retry layers documented as multiplying. | Same-origin unsigned blocks are never demoted. Fixtures must match the request body. A knob-reaches-wire probe becomes `IntentOrError`. Composite `(type, index)` merge for OpenRouter reasoning details. |
| openai-agents-python | `[read source]` | Origin gating by model on stored provider data and verbatim preservation of the original thinking-block sequence. A parallel-list design attached a signature to the wrong block (fixed). Runtime-level retry with jitter, Retry-After forms, replay-safety flag and request ids. `require_finish_reason` turns a missing finish into an error. Quota 429 not distinguished. | Keep blocks whole and ordered. Separate retry class from replay safety. Terminal-required streams. |
| LangChain and langchain-google | `[read source]` | Standard content blocks plus an `extras` side channel. Only allow-listed keys survive the round trip, which dropped redacted reasoning (open issue). Message-level provider tag gates Anthropic replay. The migration to versioned output created a large matrix of partner by output version by invoke/stream. Gemini cumulative usage is differenced. No library retry. | Opaque fields are carried whole, not through an allow-list. A stored-history version plan is needed before introducing an owned representation. Snapshot versus delta usage is a typed distinction. |
| any-llm | `[read source]` | Side channel keyed by vendor for signatures. Redacted blocks skipped. Streaming reasoning not implemented for one vendor (open). HTTP 402 classified separately from 429. A conversion bridge silently lost several history fields while returning 200. Shared live suite with no recordings. | Loss must never be silent. Distinct reasoning-replay coverage for buffered, SSE and WebSocket. |
| llm-rosetta (repository) | `[read source]` | Small YAML layer for connection and knobs with hand-written converters. Fix history is almost all code. Cross-provider reasoning is forged into foreign fields, unknown blocks are swallowed, finish reasons are conflated. A weekly job detects vendor SDK type drift. A soft-error pattern detects errors inside HTTP 200. Cross-provider metadata test pins an implementation detail, not vendor acceptance. | Fail-closed default for foreign reasoning. A drift job as a model for scheduled canaries. The in-200 error case is a fixture. The metadata test is the example of an incidental-implementation test that must not be copied. |
| Portkey gateway | `[read source]` | The "declarative" config is TypeScript objects with inline functions. Undeclared request fields vanish silently (open issue). Usage meaning differs between direct, Vertex and Bedrock routes (open issue). Truncated upstream stream ends as 200 with no signal (open issue). Retry has a wait budget but no jitter and no quota distinction. No recorded fixtures. | Unknown request fields are errors. Usage algebra is per route and tested. EOF without terminal is a failure. |
| Bifrost | `[read source]` | A remote JSON capability sheet for model facts, with a conditional-label escape that the runtime must interpret. The richest error taxonomy (quota beats 429), jitter, Retry-After parsed but recorded only (open issue). Reasoning is sent, and on a 400 stripped and retried by matching error text. Stop-reason regressions recurred for mixed text-plus-tool turns. Streaming cache double counting recurred. | Quota classified ahead of status. Origin gating before dispatch instead of error-text recovery. Captured Retry-After must reach the scheduler. Mixed text-plus-tool turns are permanent fixtures. |
| Envoy AI Gateway | `[read source]` | Typed Go translators per input/backend pair, YAML selects a translator. Single usage type with per-field set flags and cache-inclusive input. Explicit errors for unsupported content. Placeholder signature for Gemini when none is present. Streaming usage merged as cumulative set, not add. Retry delegated to the proxy. | Usage set-versus-add typed explicitly. Unsupported request content is an error. The Gemini placeholder rule is a documented opt-in, not a hidden fallback. |
| BAML | `[read source]` | Typed clients per family. A new line rewrites providers in its own language. Its own source notes signed reasoning is not yet replayable. A retry-safety notion with three values (Safe, Unknown, Unsafe). Usage meaning mismatch is documented and reported verbatim. A serde alias once made a valid response fail as a duplicate field. | Retry safety is evidence-based and separate from retry class. Field aliases must not assume exclusivity. |
| simonw/llm | `[read source]` | Plugin per vendor and a YAML only for OpenAI-shaped endpoints. Provider-namespaced opaque metadata: each plugin reads only its own namespace. | OpenRouter | `[read docs]` | Reasoning details carry a format tag naming the originating family, and must be returned unmodified and in order. Mid-stream failures arrive as in-band events and 200 bodies may contain errors. 402 is distinct from 429. Unsupported parameters are ignored unless a strict routing flag is set. Implementation is private. | Origin-tag vocabulary. In-200 error and in-stream error fixtures. A request-level strictness switch informed `IntentOrError`. Cross-model behaviour claimed by the docs is unverified. |

## 6. Architecture

| Citation | Level | What it shows | Decision informed |
|---|---|---|---|
| Parnas, *On the criteria to be used in decomposing systems into modules*, 1972, DOI 10.1145/361598.361623 | `[read abstract]` | The decomposition criterion changes flexibility and comprehensibility. | Cockburn, *Hexagonal architecture (Ports and Adapters)*, 2005 | `[read full text]` (named sections) | The core knows nothing of the outside technology. | *Anti-Corruption Layer Pattern* (Microsoft architecture guidance), page updated 2026 | `[read full text]` | Translate to protect an internal model from foreign semantics. | Mernik et al., *When and how to develop domain-specific languages*, 2005, DOI 10.1145/1118890.1118892 | `[read full text]` §§1.1–1.4, 2.2–2.5 | A DSL trades domain benefits against language implementation and maintenance cost, and an application library is often cheaper. | Descriptors hold values and closed rules only. | Hadlow, *The Configuration Complexity Clock*, 2012 | `[read full text]` (web essay) | Values grow into structured config, rule engines and DSLs, with the risk of a worse programming tool. ## 8. Known unknowns

The reports found no answer to these, and the design does not claim one.

1. **Reasoning binding.** What an opaque reasoning block binds to (model, deployment, account, API version, conversation prefix, host) is vendor-specific and partly unverified. Whether signatures interoperate between Anthropic direct, cloud-hosted and gateway routes is unverified. Open decision D4.
2. **Transport backend.** No measured evidence ranks the two candidate transport backends on footprint, shutdown behaviour or conformance effort. Open decision D1.
3. **Async core threshold.** NeoGraph's target concurrency is unknown, so the point where a blocking-only surface becomes inadequate is unmeasured. The proposed thresholds are acceptance targets, not observations. Open decision D3.
4. **Scope of non-chat features.** Long-running operations, image endpoints and the OpenRouter decisions endpoint were not compared against competitors. Open decision D2.
5. **Descriptor rule admission.** No literature gives a quantitative cutoff for how many rule kinds a data language can carry. Open decision D5.
6. **Declarative versus code defect rate.** No reviewed work controls for this. The audit has 31 rows from one self-reported audit, and all surveyed projects fixed their reasoning and usage defects in code.
7. **Unknown frame criticality.** Whether a new event is harmless or a new terminal, refusal or usage boundary cannot be decided from taxonomy alone. It needs per-family rules and recorded evidence.
8. **Idempotency per endpoint.** Supported keys, retention, payload-mismatch handling, streaming reconnection and cancellation billing are not established for any vendor. No endpoint is assumed to support them. The Idempotency-Key draft was not read.
9. **Usage algebra over time.** Modalities, server-side tools, cache-write TTLs and reasoning inclusion keep evolving. The OpenTelemetry GenAI conventions were only seen second-hand.
10. **Retry budget scope and default.** Whether to share per library instance, process, credential or vendor, and which default suits a desktop client versus a server, is workload-dependent.
11. **Canary sensitivity and cost.** No result gives a minimal probe set that detects all silent vendor changes, nor a false-positive rate. Fixture-count and bug-discovery figures from compiler or server fuzzing do not transfer.
12. **Open Responses as an oracle.** Its independent standing as a client-side oracle is unestablished: it is server-oriented and its schema is reported as OpenAI-shaped.
13. **Migration-diff governance.** Who approves an accepted difference between the current NeoGraph implementation and the new library when the old one has known defects is a process decision, not a research finding.
14. **Not covered at all.** swiftide, langchain-rust, TensorZero, Helicone, models.dev, and any vendor interoperability contract for signed reasoning were not examined.
